## 1. Обзор задачи

**Тест Даймлера по окислению (DOT — Daimler Oxidation Test)** — стандартный метод оценки
стойкости моторных масел к окислению в присутствии биотоплива и каталитических примесей
(медь + железо). Тест проводится по ASTM D445 / DIN 51453.

| Параметр | Описание |
|----------|----------|
| **Тип задачи** | Multi-output regression (2 таргета) |
| **Входные данные** | Рецептура масла (компоненты + доли) + свойства компонентов + условия теста |
| **Запрещённые алгоритмы** | XGBoost, LightGBM, CatBoost, Random Forest, Extra Trees |
| **Рекомендуемые подходы** | Deep Sets, Set Transformer, GNN, Байесовские модели |

Полезные ссылки для понимания химии:
- [Deep Sets (Zaheer et al., 2017)](https://arxiv.org/abs/1703.06114) — архитектура для
  работы с множествами переменного размера
- [Set Transformer (Lee et al., 2019)](https://arxiv.org/abs/1810.00825) — трансформер для множеств
- [Обзор химии моторных масел (Mortier et al.)](https://doi.org/10.1002/9781118700273) — Chemistry
  and Technology of Lubricants
- [ASTM D4684 / Daimler MB 229.x](https://www.astm.org/d4684-22.html) — стандарты

## 3. Таблица 1 — Смеси (train/test)

### Формат

Каждый **сценарий** (один DOT-эксперимент) представлен **несколькими строками** —
по одной на каждый компонент рецептуры. Это **long format**.

| Колонка (raw) | Колонка (трансф.) | Тип | Описание |
|---------------|-------------------|-----|----------|
| `scenario_id` | `scenario_id` | str | Идентификатор (train\_N / test\_N) |
| `Компонент` | `component_id` | str | ID компонента (напр. `Антиоксидант_5`) |
| `Наименование партии` | `batch_id` | str/int | Номер партии (числовой или `б/н`) |
| `Массовая доля, %` | `mass_fraction` | float | **Анонимизированная** трансформированная доля |
| `Температура испытания ...°C` | `temperature` | int | Температура DOT (°C) |
| `Время испытания ...ч` | `time` | int | Длительность теста (ч) |
| `Количество биотоплива ...% масс` | `biofuel_pct` | float | Содержание биотоплива (% масс) |
| `Дозировка катализатора, категория` | `catalyst_category` | int | Категория катализатора (1 или 2) |
| `Delta Kin. Viscosity KV100 ...%` | `target_viscosity` | float | **Таргет 1** (только train) |
| `Oxidation EOT ...A/cm` | `target_oxidation` | float | **Таргет 2** (только train) |

### Ключевые факты

- Train: **167 уникальных сценариев**, 2 230 строк (в среднем ~13.4 строки на сценарий)
- Test: **40 уникальных сценариев**, 524 строки
- Компонентов на сценарий: от **6 до 20** (медиана = 13)
- 112 уникальных `component_id` суммарно по обеим выборкам

> ⚠️ **Важно:** `mass_fraction` — это НЕ реальная массовая доля. Она анонимизирована
> монотонным преобразованием (порядок сохраняется, но абсолютные значения изменены).
> Тем не менее **сумма по сценарию** может использоваться как нормировочный вес.

## 5. Целевые переменные

### target\_viscosity — ΔKV100, %

Относительное изменение кинематической вязкости при 100°C после теста DOT.

| Статистика | Значение |
|------------|---------|
| Кол-во | 167 (нет пропусков) |
| Среднее | 58.3 % |
| Медиана | 4.35 % |
| Std | 197.0 % |
| Min | −37.0 % |
| Max | **1763.3 %** |
| IQR | [−16.2; 32.7] |
| IQR-выбросов | 20 сценариев |
| Z > 3 | 4 сценария |

**Распределение сильно правоскошённое**. Отрицательные значения означают
уменьшение вязкости (деполимеризация загустителя). Экстремальные значения (>500%)
указывают на образование гелеобразной структуры при сильном окислении.

> Ссылка: [Вязкость загущенных масел (Selby, NLGI)](https://www.nlgi.org/) — механизм
> нарастания вязкости при окислении связан с образованием поперечных сшивок полимерных
> молекул загустителя.

### target\_oxidation — Oxidation EOT, A/cm

Степень окисления масла в конце теста (поглощение инфракрасного излучения).

| Статистика | Значение |
|------------|---------|
| Кол-во | 167 (нет пропусков) |
| Среднее | 55.8 A/cm |
| Медиана | 47.2 A/cm |
| Std | 36.1 A/cm |
| Min | 5.61 A/cm |
| Max | 148.95 A/cm |
| IQR | [25.3; 85.8] |

**Распределение более нормальное**, но с лёгкой правой асимметрией.

> Метод: DIN 51453 (FTIR-спектроскопия). Полоса поглощения ~1710 см⁻¹ — 
> карбонильные группы (продукты окисления). Ссылка:
> [DIN 51453](https://www.din.de/en/getting-involved/standards-committees/nap/publications/wdc-beuth:din21:130014)

### Корреляция между таргетами

| Метод | r | p-value |
|-------|---|---------|
| Pearson | 0.356 | 2.4 × 10⁻⁶ |
| Spearman | 0.478 | 6.3 × 10⁻¹¹ |

Умеренная положительная корреляция: масла с высоким окислением, как правило,
также показывают рост вязкости, но не всегда (разные механизмы деградации).

| `time` | 168 ч, 216 ч | 150 / 17 сценариев |
| `biofuel_pct` | 0%, 5%, 7% | 116 / 14 / 37 сценариев |
| `catalyst_category` | 1, 2 | 158 / 9 сценариев |

### Покрытие в test

| Условие | Train unique | Test unique | Новые в test? |
|---------|-------------|------------|---------------|
| `temperature` | {150, 154, 160} | {150, 154, 160} | Нет |
| `time` | {168, 216} | {168, 216} | Нет |
| `biofuel_pct` | {0, 5, 7} | {0, 5, 7} | Нет |
| `catalyst_category` | {1, 2} | {1, 2} | Нет |

Все условия испытания в test **присутствовали в train** — экстраполяции по этим осям нет.

> ⚠️ **Дисбаланс:** `catalyst_category = 2` только в 9/167 train-сценариях (5.4%),
> но в test их 5/40 (12.5%) — доля увеличена. Профиль принципиально другой:

| Catalyst | n | Среднее ΔKV100 | Среднее EOT |
|----------|---|---------------|-------------|
| 1 | 158 | 59.5% | 54.5 A/cm |
| **2** | 9 | **38.4%** | **79.3 A/cm** |

Category 2 = более агрессивный окисляющий катализатор (возможно Fe₃O₄ вместо Cu/Fe).
Результат: ниже деградация вязкости, но сильнее химическое окисление.

### Влияние условий на таргеты (Spearman)

| Условие | r с ΔKV100 | r с EOT | Значимость |
|---------|-----------|---------|-----------|
| `biofuel_pct` | **+0.673** | +0.232 | *** |
| `temperature` | **−0.619** | −0.354 | *** |
| `time` | **+0.463** | +0.303 | *** |
| `catalyst_category` | +0.151 | +0.152 | ~(p≈0.05) |

**Вывод:** Биотопливо и температура — наиболее важные внешние факторы.
Более высокая температура снижает ΔKV100 (вероятно, деструкция загустителя).
Биотопливо резко ускоряет окисление (пероксиды жирных кислот).

> Механизм влияния биотоплива:
> [Биодизель в моторных маслах (Fang & McCormick, 2006)](https://doi.org/10.4271/2006-01-3300)

## 8. Качество данных

### Проблемы единиц измерения (обнаружены в EDA и исправлены)

Три свойства имеют **разные обозначения одной единицы** в raw-данных.
Трансформер `ComponentsTransformer` устраняет это автоматически:

| Свойство | Старые единицы | Новые единицы | Метод |
|----------|---------------|--------------|-------|
| Индекс вязкости (ГОСТ 25371) | `-` (11) и `–` (77) | `dimensionless` | `_normalize_units` |
| Испаряемость NOACK (ASTM D5800) | `%` (52) и `% масс` (10) | `wt%` | `_normalize_units` |
| Плотность при 15°С (ASTM D4052) | `г/см³` (~1.0) и `кг/м³` (~850) | `g/cm3` | `_fix_density_units` |

**Детергенты** → типовые значения в г/см³ (0.98–1.2 г/см³).  
**Базовые масла + депрессорные** → партийные значения в кг/м³ (800–885 кг/м³).  
После конвертации `/1000` все значения консистентны (0.80–0.88 г/см³).

### ⚠️ Критическая аномалия 1: один компонент дважды в сценарии

**91 случай**, когда одна и та же пара `(scenario_id, component_id)` встречается дважды
(иногда с одним `batch_id`, но разными `mass_fraction`).

Пример (train_10): `Базовое_масло_1` встречается с долями 23.138 и 30.454.

**Интерпретация**: Вероятно, масло добавлялось в два приёма (разные стадии компаундирования).
При агрегации нужно **суммировать** доли, а не брать только первую.

### ⚠️ Критическая аномалия 2: сумма mass_fraction ≠ 100

Анонимизированные доли **не суммируются до 100%**. Реальные суммы по сценарию:
- Мин: 247, Медиана: 589, Макс: 956

Это подтверждает монотонное, но нелинейное преобразование исходных долей.
**Для весов используйте нормировку**: `weight = mass_fraction / sum(mass_fraction)`.

### ⚠️ Критическая аномалия 3: 14 компонентов без числовых свойств

Следующие компоненты **полностью слепые** (0 числовых свойств, только NaN в value):

| Компонент | Тип |
|-----------|-----|
| Антиоксидант_5 | Antioxidant |
| Антипенная_присадка_1 | Anti-foam |
| Антипенная_присадка_2 | Anti-foam |
| Противоизносная_присадка_3, 4, 6, 9, 12, 13, 14, 15, 16, 19, 23 | AW |

Из 8 новых компонентов в test двое (`_9`, `_12`) тоже полностью без свойств.
Модель должна уметь работать с отсутствием характеристик (imputation / learnable embedding).

### Предельные значения (`<10`, `>95`)

7 строк содержат значения вида `<10` или `>95`. Стратегии обработки:
- Взять числовую часть как оценку снизу/сверху (`10`, `95`)
- Заменить на `NaN`
- Использовать специальные токены в эмбеддингах

### Нечисловые категориальные свойства

- `Класс субстрата` (Базовое масло): `гидрокрекинг`, `Вторичный` → one-hot или эмбеддинг
- `Тип химического соединения` (Детергент): `Сульфонат кальция`, `Фенолят кальция` → функционально важно
- `Химическая природа` (Дисперсант): `TEPA`, `Неборированный` → важно для синергии

### Пропуски

Не все компоненты имеют все 94 свойства. Покрытие сильно зависит от типа:

| Тип компонента | Плотность покрытия свойств |
|----------------|--------------------------|
| Базовое масло | Высокая (34 свойства на тип) |
| Детергент | Высокая (26 свойств) |
| Антипенная присадка | Низкая (4 свойства) |
| Депрессорная присадка | Низкая (4 свойства) |

## 9. Ключевые корреляции с таргетами

### С target\_viscosity (ΔKV100)

> Все значения — Spearman r на средневзвешенных по сценарию свойствах.

| Свойство | r | Интерпретация |
|----------|---|---------------|
| `biofuel_pct` (условие) | **+0.673** | Биотопливо ускоряет деградацию загустителя |

## 10. Синергия и антагонизм

### Экспериментальное свидетельство синергии

При одинаковом **наборе типов** компонентов (но разных конкретных компонентах внутри типа)
таргеты варьируются очень сильно:

| Состав (типы компонентов) | Сценариев | Среднее ΔKV100 | CV ΔKV100 |
|---------------------------|-----------|---------------|----------|
| Все 9 типов (+ Mo) | 78 | 112.5% | **2.42** |
| Все типы без Mo | 38 | 21.0% | **3.96** |
| 7 типов без Mo, без AF | 20 | 12.3% | **2.52** |

**CV > 2** означает, что конкретный выбор компонента внутри типа меняет таргет в 2+
раза сильнее, чем среднее значение. Это прямое свидетельство **синергии/антагонизма**.

### Практический вывод

Модель **не может** использовать только тип компонента — ей необходимы
индивидуальные химические свойства каждого конкретного компонента (или эмбеддинг).

> Ссылка по синергии антиоксидантов:
> [Synergism and antagonism in antioxidant blends (Ingold & Pratt, 2014)](https://doi.org/10.1021/cr500226n)
